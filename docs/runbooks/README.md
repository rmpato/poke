# Runbooks

<sub>[Docs](../README.md) · **Runbooks**</sub>

Short, specific procedures for the things that need doing more than once.

| Runbook | When |
|---|---|
| [release.md](release.md) | Cutting a release, and what to do when one goes wrong |
| [screenshots.md](screenshots.md) | Regenerating the documentation images after a UI change |
| [curl-option-table.md](curl-option-table.md) | A new curl version, or a CI failure about the option table |
| [capture-bug.md](capture-bug.md) | Someone reports that pogo behaves differently from curl |
| [history-recovery.md](history-recovery.md) | A history file that is damaged, enormous, or holds a secret |
| [security-response.md](security-response.md) | A vulnerability report arrives |

Each one assumes you have the repository checked out and `make check` passing.
